# Plex Studios

**Minecraft plugins and developer tools built for performance, flexibility, and reliability.**

Plex Studios is an independent development studio founded by [Applex](https://github.com/ApplexDev), focused on building practical software for Minecraft servers.

From lightweight quality-of-life plugins to advanced configuration systems and custom gameplay mechanics, our goal is to create software that is easy to use, straightforward to configure, and reliable in production.

We believe good software should solve real problems without introducing unnecessary complexity.

## Featured Project

### [PlexVariables](https://github.com/PlexStudios/PlexVariables)

**Custom variables. Advanced logic. Complete control.**

A configurable variable engine for Paper servers, extending PlaceholderAPI with powerful tools for managing dynamic server data.

**Features**
- Custom PlaceholderAPI variables defined through YAML
- Static, conditional, expression, and stored variables
- Nested variables and reusable logic
- Safe mathematical expression evaluation
- Persistent player and global data using SQLite
- Automatic configuration discovery
- Debugging tools and safe configuration reloads

*Status: Public beta. Manual server testing is pending.*

## Our Projects

### [PlexKillstreaks](https://github.com/PlexStudios/PlexKillstreaks)

A lightweight, customizable killstreak system for Paper servers.

Track player streaks, configure milestone rewards, display leaderboards, and integrate statistics with PlaceholderAPI.

Includes SQLite persistence, anti-farming protection, configurable announcements, sound effects, and progress indicators.

### [PlexDeathCoords](https://github.com/PlexStudios/PlexDeathCoords)

A simple and reliable way for players to find their most recent death location.

Automatically records death coordinates across worlds and dimensions, with configurable messages, persistent storage, and convenient commands.

Designed to remain lightweight, with no additional plugin dependencies.

## Upcoming & Experimental Projects

The following projects are being developed or explored. Features and release plans may change.

### PlexMenus

A flexible inventory GUI framework designed to simplify custom Minecraft menus.

Focused on automatic menu discovery, YAML configuration, customizable actions, and requirement systems supporting permissions, economy checks, cooldowns, and player groups.

### PlexDeathSwap

A multiplayer DeathSwap minigame built around creative traps, strategic preparation, and unpredictable player swaps.

Planned gameplay includes survival and creative modes, progressively shorter swap intervals, multiple rounds, and configurable match rules.

### PlexAware

An experimental survival quality-of-life assistant focused on contextual awareness, inventory protection, and subtle player feedback.

Designed to enhance everyday survival gameplay without becoming intrusive.

*Development repositories and further information will be made available when appropriate.*

## Our Development Approach

Our projects follow a few core principles:

- **Performance first:** Avoid unnecessary overhead and expensive operations.
- **Configuration without complexity:** Flexible settings with sensible defaults.
- **Reliability:** Predictable behavior, safe data handling, and proper error recovery.
- **Clean architecture:** Maintainable code with clear responsibilities.
- **Compatibility:** Target supported platforms and document tested versions accurately.
- **User experience:** Simple commands, clear messages, and intuitive interactions.
- **Minimal dependencies:** Avoid introducing unnecessary external requirements.
