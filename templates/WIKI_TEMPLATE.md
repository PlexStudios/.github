# Project Wiki Structure

Use this template only for projects complex enough to need a Wiki.

## Recommended Pages

### Home

Include:

- short project description
- current stable version
- compatibility summary
- navigation links
- quick installation link
- support link

### Installation

Include:

- requirements
- installation steps
- first startup
- generated files
- dependency notes

### Quick Start

Include the shortest path from installation to a working setup.

### Configuration

Include:

- setting reference
- defaults
- validation rules
- reload behavior
- examples

### Commands and Permissions

Use tables.

### Integrations

Document each supported external plugin or API.

### Placeholders

Use a table with:

- placeholder
- description
- example output
- availability requirements

### Storage and Data

Use when the plugin persists data.

Document:

- storage location
- lifecycle
- migration behavior
- backup guidance
- corruption/failure behavior where relevant

### Advanced Usage

Complex configuration patterns, composition, or integration examples belong here.

### Troubleshooting

Structure by symptom and resolution.

### FAQ

Only include questions that users are likely to ask.

## Navigation

Each page should link naturally to relevant neighboring pages.

Do not duplicate the entire README into the Wiki.
