# Support

For project-specific support, use the issue tracker of the relevant Plex Studios repository.

Before opening an issue:

1. Confirm the problem still occurs on the version you are using.
2. Check the project README and PlexDocs.
3. Gather the relevant server version, plugin version, logs, and reproduction steps.

Do not publish passwords, tokens, database credentials, private configuration secrets, or other sensitive information in public issues.
